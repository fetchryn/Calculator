

# 🧮 Calculator

**Pure JavaScript Calculator**

---

## 📌 Project Overview

The Calculator Web Application is a responsive, browser-based calculator that performs basic arithmetic operations such as addition, subtraction, multiplication, division, and percentage calculation. The project is built using **HTML, CSS, and JavaScript**, focusing on proper DOM manipulation, event handling, input validation, and clean code organization.
